# Independent continuation

This project is shared as-is. No maintenance, support or pull request review is promised. To continue development, fork it and document what you change, which models you test and how you handle private account data. Preserve all original MIT copyright and license notices. Do not imply that the original upstream authors maintain or endorse the Homey port.

Run the existing tests from `app` with `node --test tests/*.test.js`. Homey CLI technical validation can be run there with `homey app validate --level publish`. These checks do not replace tests against an actual vehicle.
