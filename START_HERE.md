Download `Zeekr_Homey_v0.2.1.zip` under Assets. Extract the complete ZIP, then follow [SETUP.md](SETUP.md) for key extraction, Homey installation and pairing. Read [FEATURES.md](FEATURES.md) before trying commands.

The documented extraction route supports only the exact analysed EU 2.9.9 build. No APKs, API keys or account credentials are included. A routine update keeps your existing working configuration; it does not need fresh extraction.
