# Validation report — Zeekr by RG Labs 0.1.0

Date: 2026-10-29. Scope: private Homey Pro beta source bundle.

## Completed

- Homey CLI 4.6.2: `homey app validate --level debug` — passed without warnings in the final source configuration.
- 28 app tests passed under Node.js 22, matching the Homey target runtime.
- HMAC request signing, app-signature canonicalization and AES-CBC VIN encryption matched synthetic fixtures generated by executing the pinned Fryyyyy Python implementation. No real credentials or keys were used.
- Mocked full EU login and shared-vehicle discovery passed, including optional API rejections, persisted-session reuse, simultaneous token expiration, throttled failed login and API rate-limit backoff.
- Request timeout does not retry a remote POST. Error messages do not include raw response bodies or credentials.
- Telemetry tests covered unknown/missing values, true zero, kW-to-W conversion, partial charging endpoint failure, stale-state Flow refusal and concurrent polling.
- Device tests covered command acceptance without optimistic telemetry updates and cancellation during deletion.
- App/pairing tests covered failed configuration replacement, persistence, disconnect, duplicate VIN handling and credential-free device identifiers.
- Pairing/settings JavaScript exercised with documented Promise/callback bridge stubs.
- Wysie's included runtime-key script: 7 upstream mock tests passed.
- Key merging helper: 3 tests passed; source files remain unmodified and incomplete results are rejected.
- Wysie's static extractor started successfully with the required Python dependencies and displayed its CLI help.

## Not verified

- No installed Zeekr 3.1.1 APK was supplied; no static or runtime extraction was performed on that build.
- No real Zeekr account login, EU endpoint acceptance, car-status response or remote command was tested.
- No installation or UI interaction was performed on a physical Homey.
- No Zeekr 001 model compatibility has been established. Command payloads follow upstream's implementation, whose documented vehicle focus is 7X.
- No Homey App Store publishing or certification was performed. Debug validation verifies package structure and manifests; it does not certify live vehicle behavior.

## Reproduce

In `app/` with Node.js 22+:

```sh
npm test
homey app validate --level debug
```

In the bundle root:

```sh
node --test tools/wysie-key-extractor/tests/runtime_keys.test.js
python -m unittest discover -s tools -p 'test_*.py'
```

To regenerate the comparison fixtures, install `requests` and `pycryptodome` into a Python virtual environment, then run `python tools/generate_protocol_fixtures.py`. Exact upstream commits are recorded in `UPSTREAM_VERSIONS.json`.
