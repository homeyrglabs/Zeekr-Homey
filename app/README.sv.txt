Anslut din europeiska Zeekr till Homey Pro för att följa batterinivå, räckvidd och laddstatus samt begära laddning eller kupéklimat via Flows. Kräver ett Zeekr EU-konto och en komplett giltig API-nyckelfil som du tar fram separat. Home Assistant behövs inte.

Inofficiell community-integration som delas i befintligt skick, utan löfte om löpande underhåll eller support. Kompatibilitet och bilkommandon behöver testas mot din modell. Ändringar i Zeekrs API kan göra att integrationen slutar fungera.
